# roles/

하위 폴더명 = `role_id` (서비스 브랜드명 아님).

바인딩·쓰기 소유의 기준은 `AI_ROSTER.md`. 여기는 폴더 안내만 둔다.

| 폴더 | 관여 |
|------|------|
| `curator/` · `analyst/` · `producer/` | 상시 (파이프라인) |
| `director/` | 호출 시 (파이프라인 외부 · 규격·승인·조정) |

- `ROLE.md` — 책임·금지·입출력·쓰기  
- `PROMPT.md` — 세션 절차 (글로벌과 중복 최소)

공통 계약은 상위 `PROMPT.md`에만 둔다.
