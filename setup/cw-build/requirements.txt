# setuptools 82.0.0 에서 pkg_resources 가 삭제됐는데, chipwhisperer 6.0.0 은
# capture/trace/TraceWhisperer.py 에서 그것을 import 한다. 이 모듈은 `import
# chipwhisperer` 만으로 함께 로드되므로, 82 이상이 깔리면 TraceWhisperer 를 쓰지
# 않는 노트북까지 전부 첫 줄에서 죽는다.
#
# python:3.9 이미지는 setuptools 를 기본 탑재(79.0.1)해서 이 줄이 "already satisfied"
# 로 무시됐지만, python:3.12 이미지는 setuptools 를 탑재하지 않으므로 이제 이 줄이
# 실제 설치 버전을 결정한다. 상한을 푸는 조건은 chipwhisperer 가 pkg_resources 를
# importlib.resources 로 옮기는 것이다 (unicorn 은 이미 그렇게 했다).
#
# 이 저장소에서 버전을 고정하는 유일한 패키지다. 나머지는 최신을 따라간다.
#
# 알아둘 부작용: 80.0 부터는 pkg_resources import 시 UserWarning 을 띄우고 이는 기본
# 필터에서도 보이므로, 노트북 첫 셀에 영문 경고가 한 번 찍힌다 (동작에는 문제 없음).
# 경고까지 없애려면 setuptools==79.0.1 로 낮추면 되지만, 그만큼 최신에서 멀어진다.
